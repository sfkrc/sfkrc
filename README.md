## Featured Projects

### Chicago Traffic Crash Severity Analysis

Analyzed 547,843 reported traffic crashes in Chicago from 2021–2025 to identify patterns and factors associated with severe crash outcomes.

- Performed data cleaning, exploratory data analysis, and statistical testing using Python
- Used SQL to analyze crash severity across lighting conditions, time periods, days of the week, and contributing causes
- Identified higher severe-crash rates during late-night hours and across several high-risk driver-related factors
- Applied Chi-Square tests and Cramér's V to evaluate statistical associations
- Built a reproducible analysis using Python, Pandas, SQL, SciPy, and Matplotlib
